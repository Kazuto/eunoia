# useRelativeTime

A lightweight composable for formatting relative time.

## Defaults

<table class="w-full">
  <thead>
    <tr>
      <th>Option</th>
      <th>Default</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>locale</td>
      <td>en</td>
    </tr>
    <tr>
      <td>interval</td>
      <td>60000</td>
    </tr>
  </tbody>
</table>

## Usage

```html
<script
  setup
  lang="ts"
>
  import { useRelativeTime } from "@/composables/useRelativeTime";

  const { relative, date, time } = useRelativeTime(
    new Date("2023-01-01T00:00:00.000Z"),
    {
      locale: "en",
      interval: 60000,
    }
  );
</script>

<template>
  <p>{{ relative }}</p>
  <p>{{ date }}</p>
  <p>{{ time }}</p>
</template>
```
