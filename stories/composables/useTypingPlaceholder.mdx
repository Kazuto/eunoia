# useTypingPlaceholder

A composable that creates an animated typing placeholder that cycles through multiple strings with a typewriter effect.

Users who ask for reduced motion (`prefers-reduced-motion: reduce`) see the first string, without animation. The strings can also be a ref or a getter, such as translations: when they change, the animation starts over with the new ones.

```ts
const { t } = useI18n();
const { placeholder } = useTypingPlaceholder(() => [
  t("search.keys"),
  t("search.text"),
]);
```

## Usage

### Basic Example

```vue
<script setup lang="ts">
import { onMounted, onUnmounted } from "vue";
import { Input } from "@thkzt/eunoia";
import { useTypingPlaceholder } from "@/composables/useTypingPlaceholder";

const { placeholder, animate, stop } = useTypingPlaceholder(
  ["John Doe", "Jane Smith", "Alex Johnson"],
  { autoStart: false }
);

onMounted(() => animate());
onUnmounted(() => stop());
</script>

<template>
  <Input :placeholder="placeholder">Name</Input>
</template>
```

### Custom Animation Speed

```vue
<script setup lang="ts">
import { onMounted, onUnmounted } from "vue";
import { useTypingPlaceholder } from "@/composables/useTypingPlaceholder";

const { placeholder, animate, stop } = useTypingPlaceholder(
  ["admin@company.com", "hello@startup.io"],
  {
    typingSpeed: 80, // Faster typing
    deletingSpeed: 30, // Faster deleting
    pauseDuration: 1500, // Shorter pause
  }
);

onMounted(() => animate());
onUnmounted(() => stop());
</script>

<template>
  <Input
    type="email"
    :placeholder="placeholder"
    >Email</Input
  >
</template>
```

### Multiple Inputs

```vue
<script setup lang="ts">
import { onMounted, onUnmounted } from "vue";
import { useTypingPlaceholder } from "@/composables/useTypingPlaceholder";

const {
  placeholder: namePlaceholder,
  animate: animateName,
  stop: stopName,
} = useTypingPlaceholder(["John Doe", "Jane Smith", "Alex Johnson"]);

const {
  placeholder: emailPlaceholder,
  animate: animateEmail,
  stop: stopEmail,
} = useTypingPlaceholder([
  "admin@company.com",
  "hello@startup.io",
  "contact@business.org",
]);

onMounted(() => {
  animateName();
  animateEmail();
});

onUnmounted(() => {
  stopName();
  stopEmail();
});
</script>

<template>
  <Input :placeholder="namePlaceholder">Name</Input>
  <Input
    type="email"
    :placeholder="emailPlaceholder"
    >Email</Input
  >
</template>
```

### Slow, Deliberate Typing

```vue
<script setup lang="ts">
import { onMounted, onUnmounted } from "vue";
import { useTypingPlaceholder } from "@/composables/useTypingPlaceholder";

const { placeholder, animate, stop } = useTypingPlaceholder(
  ["Think carefully...", "Take your time...", "No rush..."],
  {
    typingSpeed: 200, // Slow typing
    deletingSpeed: 100, // Slow deleting
    pauseDuration: 3000, // Long pause
  }
);

onMounted(() => animate());
onUnmounted(() => stop());
</script>

<template>
  <Textarea :placeholder="placeholder">Your thoughts</Textarea>
</template>
```

## API

Returns an object with the placeholder ref, animate function, and stop function.

**Returns:** `{ placeholder: Ref<string>, animate: () => void, stop: () => void }`

- `placeholder` - A reactive reference to the current placeholder text
- `animate` - Function to start the animation (call in `onMounted`)
- `stop` - Function to stop the animation (call in `onUnmounted`)

## Behavior

The animation follows this cycle:

1. **Type** the first placeholder character by character
2. **Pause** for the configured duration
3. **Delete** the text character by character
4. **Move** to the next placeholder
5. **Repeat** infinitely

Call the `animate()` function in your component's `onMounted()` hook to start the animation, and call `stop()` in `onUnmounted()` to clean up.

## Use Cases

- **Form fields** - Show example inputs to guide users
- **Search boxes** - Display popular search queries
- **Email signup** - Demonstrate email format variations
- **Landing pages** - Create engaging, dynamic placeholders
- **Multi-step forms** - Provide contextual examples for each field

## Performance

The composable is lightweight and uses `setTimeout` for animations. Each instance runs independently, so multiple typing placeholders on the same page won't interfere with each other.

Remember to call `stop()` in `onUnmounted()` to prevent memory leaks when the component is destroyed.
